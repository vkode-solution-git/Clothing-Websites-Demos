# Clothing-Websites-Demos

Collection of clothing-store website demos and static previews.

## Zartari storefront — run locally

The Zartari folder is an HTTrack static mirror, not an original Shopify source project. For the local VS Code setup and known limitations, see [`zartari-clothing-website/README.md`](zartari-clothing-website/README.md).

Quick start on macOS:

```bash
cd zartari-clothing-website
npm run dev
```

Then open <http://127.0.0.1:8000>. Python 3 is required; `npm install` is not required.
